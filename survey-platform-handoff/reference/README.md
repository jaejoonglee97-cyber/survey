# reference - 검증된 프로토타입 (Apps Script 버전)

새 구현의 **동작 사양**으로 쓰는 자료임. 그대로 복사해 쓰는 코드가 아니라 TypeScript로 옮겨 쓸 기준임.

| 파일 | 용도 |
|---|---|
| `Survey.gs` | 문항 md 해석·검증, 응답 검증, 집계, 결과보고서 문안, 마감 판정(순수 함수). Phase 2에서 `survey-core`로 이식 |
| `survey.test-cases.js` | 위 로직을 검증한 시험 사례. 기대값이 새 구현의 명세 |
| `Respondent.html` | 응답 화면의 상호작용(복수 선택 제한, 직접입력, 필수 검증, 진행 막대). Phase 3에서 이식 |
| `Dashboard.html` | 대시보드의 계산·렌더링 로직(눈금자, 분포 막대, 연도별 추이, 필터). Phase 5에서 이식 |
| `dashboard-preview.html` | 예시 데이터로 만든 대시보드 미리보기(브라우저에서 바로 열림) |
| `samples/2026-healingcamp.md` | 힐링캠프 만족도 설문 12문항 샘플 |
| `samples/template-event.md` | 행사·교육 공통 템플릿 7문항 |

프로토타입에서 확인된 주의점(새 구현에서도 지킬 것)
- 존재하지 않는 날짜(예: 2월 31일)를 마감일로 받지 않음. 자바스크립트 `Date`는 다음 달로 넘겨 버리므로 직접 검증함.
- 마감 시각은 표기한 분이 끝날 때(`:59.999`)까지 접수함.
- 스프레드시트 수식 주입(`= + - @` 시작)은 저장·CSV 내보내기 모두에서 막음.
- 화면 시험에서 `body.textContent`로 문구를 찾으면 스크립트 원문에 걸려 거짓 통과가 나올 수 있으므로, 화면 영역만 검사함.
