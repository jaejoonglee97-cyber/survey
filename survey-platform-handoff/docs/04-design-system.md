# 04. 디자인 시스템 · 화면 구성

## 0. 원칙

- **기존 '서사협 회원서비스 · 업무 홈' 화면의 디자인을 그대로 따름.** 새 모듈은 같은 사이드바·상단바·카드 언어를 쓰며, 새로운 시각 언어를 만들지 않음. 기존 저장소에 같은 역할의 컴포넌트(Sidebar, PageHeader, StatCard, Banner 등)가 있으면 **재사용**하고, 없는 것만 아래 사양으로 새로 만듦.
- 아래 값은 제공된 스크린샷(가로 1569px)에서 **픽셀 색을 직접 추출**한 값과 눈대중 치수임. 저장소에 디자인 토큰이 이미 있으면 그 값을 우선하고, 이 문서는 차이가 있을 때의 참고용으로 씀.
- 이 모듈에서 눈에 띄는 요소는 하나로 제한함: **1~5점 '만족도 눈금'**(결과·대시보드). 나머지는 기존 화면처럼 조용하게 둠.

## 1. 색 (스크린샷에서 추출)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#f1f3f2` | 페이지 배경 |
| `--sidebar` | `#f9faf9` | 사이드바 배경 |
| `--surface` | `#ffffff` | 카드, 선택 상자, 버튼 |
| `--line` | `#e5e9e5` | 구분선, 카드 테두리 |
| `--ink` | `#1c2420` | 제목·본문 |
| `--muted` | `#858e86` | 보조 문구(스크린샷 값) |
| `--lime` | `#d5f26b` | 현재 메뉴 강조, 로고, 주요 포인트 |
| `--lime-soft` | `#e1f89b` | 배너 위 버튼, 선택 상태 배경 |
| `--teal` | `#2a9d97` | 배너, 연결 상태 점, 강조 면 |
| `--lav` | `#d1caf7` | 통계 카드 1(라벤더) |
| `--blue` | `#bad6fb` | 통계 카드 2(하늘) |
| `--mint` | `#b1e7c7` | 통계 카드 3(민트) |
| `--avatar` | `#dce9d6` | 아바타 배경 |

**접근성 보정(명도 대비 계산 결과)**: 스크린샷의 `--muted`는 흰 배경에서 3.4:1, `--bg` 위에서 3.0:1로 작은 글씨 기준(4.5:1)에 못 미침. 새 화면의 보조 문구는 `--muted-text: #667069`(흰 배경 5.1:1, `--bg` 위 4.6:1)를 쓰고, `--muted`는 비활성 표시나 큰 글씨에만 씀. 배너 위 흰 글씨(`#2a9d97` 위 3.3:1)는 **18.7px 이상 굵은 글씨**에만 쓰고, 작은 안내 문구는 `--ink`(4.8:1) 또는 더 진한 `#1f7a74`(흰 글씨 5.1:1) 배경을 씀. 파스텔 카드 위의 `--ink` 글씨는 모두 10:1 이상이라 문제 없음.

|---|---|
| 1 | `#e58a6f` |
| 2 | `#f0b98a` |
| 3 | `#e3e6df` |

## 2. 타이포그래피·형태

- 서체: 스크린샷의 서체는 **Pretendard 계열로 보임**(저장소가 쓰는 서체를 확인하고 그대로 따름). 없으면 `Pretendard Variable, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`.
- 눈대중 크기: 페이지 제목 32px/굵게, 통계 숫자 40px/굵게, 카드 제목 17px/굵게, 본문 14~15px, 보조 12~13px, 영문 눈썹 글씨(eyebrow) 10px·자간 0.14em·대문자·600.
- 반경: 카드 16~20px, 사이드바 활성 항목 12px, 로고 12px, 버튼 10px, 칩·배지 999px.
- 그림자는 거의 없음(1px 테두리 `--line`와 배경 대비로 구분).
- 아이콘: 1.5px 선형 아이콘(lucide 계열과 유사). 저장소의 아이콘 라이브러리를 따름.

## 3. 레이아웃 (1569px 폭 기준 치수)

| 요소 | 치수 |
|---|---|
| 사이드바 | 폭 250px, 우측 1px `--line`, 배경 `--sidebar` |
| 사이드바 활성 항목 | 높이 약 51px, 좌우 여백 11px, `--lime` 배경, 아이콘+라벨 굵게 |
| 상단바 | 높이 약 78px, 흰 배경, 하단 1px `--line`. 좌: 빵부스러기(회원서비스 › 업무 홈). 우: '공개 사이트 · 기록 보호' 칩(자물쇠), 아바타 |
| 본문 | 좌우 여백 약 32px, 카드 간격 약 20px |
| 통계 카드 | 높이 약 163px, 3열 균등, 라벨(작은 굵은 글씨) → 숫자(크게) + 단위(작게) → 보조 설명. 우상단 아이콘, 우하단 장식 원(연한 동심원) |
| 배너 | 높이 약 226px, `--teal` 배경, 좌측 문구(굵은 흰 글씨 + 보조 + `--lime-soft` 버튼), 우측 일러스트 |
| 목록 카드 | 흰 배경, 제목+개수 배지, 우측 '전체 보기 ↗', 밑줄 탭, 행 목록 |
| 페이지 머리 | 눈썹 글씨 → 제목 → 설명. 우측에 연도 선택(흰 상자)과 '새로고침' 버튼 |
| 상태 줄 | 날짜 / 연결 상태(초록 점 + '… 연결됨') / '마지막 갱신 …' |

**반응형**: 1024px 미만에서 사이드바는 접힘(햄버거), 통계 카드는 1열, 배너 일러스트는 숨김. 응답 화면은 이 레이아웃을 쓰지 않고 별도의 단일 컬럼임(5절).

## 5. 새 화면 구성 (같은 언어로)

사이드바 '워크스페이스' 아래에 **'만족도 설문'** 그룹을 추가함: 설문 홈 · 설문 목록 · 새 설문 · 만족도 대시보드. 열람자(viewer)에게는 '만족도 대시보드'만 보임.

### 5.1 설문 홈 (`/survey`)
```
눈썹: SEOUL ASSOCIATION OF SOCIAL WORKERS
만족도 설문                                      [2026년 ▾] [새로고침]
사업·행사가 끝나면 설문을 만들고, 응답과 결과를 한곳에서 확인하세요.
┌ 라벤더 ───────┐ ┌ 하늘 ────────┐ ┌ 민트 ────────┐
│ 진행 중 설문   │ │ 이번 주 마감   │ │ 올해 응답     │
│ 4 건          │ │ 2 건          │ │ 1,284 명      │
└───────────────┘ └──────────────┘ └──────────────┘
┌ 틸 배너 ───────────────────────────────────────────────┐
│ 새 설문, 대화로 만들어 보세요.            (일러스트)       │
│ 알고 싶은 점을 말하면 문항이 만들어져요.                   │
│ [새 설문 만들기 →]                                       │
└────────────────────────────────────────────────────────┘
┌ 마감 임박 설문 [2] ─────────────┐ ┌ 최근 마감 결과 ───────────┐
│ 힐링캠프  D-3  응답 31/40 (78%)  │ │ 평균 4.4 · 긍정 91% (눈금) │
│ …                              │ │ [대시보드로 ↗]            │
└────────────────────────────────┘ └──────────────────────────┘
```

### 5.2 새 설문 - 대화형 설계 (`/survey/new`)
- 좌우 분할: 왼쪽 **대화**(흰 카드, 메시지 말풍선: AI는 `--surface` + 테두리, 사용자는 `--lime`), 오른쪽 **설문 초안**(흰 카드).
- 초안 카드 상단: '**AI 보조 작성 · 담당자 최종 검토**' 칩, 아래에 문항 목록(번호, 유형 칩, 필수 표시, 대표 문항은 `--lime` 별 표시). 문항은 클릭하면 인라인 편집, 드래그로 순서 변경, 휴지통으로 삭제.
- 초안 카드 하단 고정 영역: **점검 패널**(오류 n · 확인 n · 약 N분)과 '미리보기', '확정하고 게시 설정으로' 버튼(오류가 있으면 비활성 + 사유 표시).
- 입력창 아래 안내: "개인정보는 입력하지 마십시오."
- 상단 접힘 영역에 기본 정보 폼. 모바일에서는 탭(대화 | 초안)으로 전환.
- AI가 응답하는 동안 초안에서 바뀐 문항을 `--lime-soft`로 잠깐 강조함(움직임은 한 번뿐).

### 5.3 설문 목록 (`/survey/list`)
카드 안 표: 제목 · 분류 · 사업명 · 마감 · 응답/대상(응답률) · 상태 칩(진행 중=`--lime-soft`, 마감=`--line`, 초안=`--lav`). 행 클릭 시 결과로 이동. 행 우측 메뉴: 링크 복사, 마감일 변경, 지금 마감(2단계 확인), 삭제(응답 0건일 때만).

### 5.4 설문 결과 (`/survey/[id]/results`)
상단 요약(통계 카드 3개: 응답 수 · 응답률 · 대표 만족도 평균) → 문항별 결과 카드(선택형 막대, 5점은 분포+평균, 서술은 목록) → '결과보고서 문안(초안)' 카드(복사 버튼) → 원자료 CSV(담당자만).

### 5.5 만족도 대시보드 (`/survey/dashboard`)
이미 만들어 둔 예시 화면 `reference/dashboard-preview.html`의 구성을 따름: 요약 → **만족도 눈금**(전체·분류별) → 사업·행사별(눈금 + 분포 막대) → 연도별 추이. 필터(연도·분류)는 `--lime` 활성 칩. 위 눈금 색 띠를 사용하고, 5건 미만 설문은 '수치를 표시하지 않음' 안내를 보여 줌.

### 5.6 응답 화면 (`/s/[slug]`, 공개)
- 로그인·사이드바 없는 단일 컬럼(최대 640px), 배경 `--bg`, 카드 흰색.
- 상단: 설문 제목, '마감 · 문항 수 · 무기명', 안내문. 얇은 진행 막대(`--teal`).
- 선택지는 큰 터치 영역(48px 이상). 선택 상태는 `--lime-soft` 배경 + `--ink` 테두리 2px. 5점 문항은 5개 동그란/네모 버튼과 양 끝 라벨.
- 오류는 해당 문항 배경을 연하게 강조하고 상단에 한 줄 안내함. 제출 버튼은 `--ink` 배경 + 흰 글씨 또는 `--lime` 배경 + `--ink` 글씨(저장소 버튼 규칙을 따름).
- 마감·없는 링크·제출 완료 화면은 가운데 정렬 안내.
- `reference/Respondent.html`(프로토타입)의 상호작용(복수 선택 개수 제한, 직접입력 칸 표시, 필수 검증)을 그대로 옮김.

## 6. 접근성·품질 기준

- 모든 입력에 연결된 레이블, 키보드 초점 표시(3px 외곽선), 터치 영역 44px 이상
- 색만으로 의미를 전달하지 않음(상태 칩에 글자 포함, 눈금에 숫자 표시)
- `prefers-reduced-motion` 존중, 움직임은 사용자 동작에 대한 반응 위주
- 모든 사용자 입력 문자열은 텍스트로만 렌더링(HTML 주입 금지). `dangerouslySetInnerHTML` 사용 금지
- 360px, 768px, 1280px에서 가로 스크롤이 생기지 않음
